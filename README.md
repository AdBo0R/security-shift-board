# Security Shift Board — لوحة ورديات الأمن

لوحة تفاعلية لعرض ورديات الأمن الأربع (A / B / C / D) لأي تاريخ.

- دورة 24 يوم: 6 أيام صباح (6–14) ← يومان إجازة ← 6 أيام ليل (22–06) ← يومان إجازة ← 6 أيام عصر (14–22) ← يومان إجازة
- أزرار ‹ › للتنقل يوم بيوم، أو اضغط على التاريخ لاختيار أي يوم
- شريط 14 يوم ملوّن لكل وردية يوضّح الوردية القادمة

## التشغيل
افتح `index.html` في المتصفح — ملف واحد بدون أي تبعيات.

## ضبط الدورة
عدّل `anchor` لكل وردية في سكربت `index.html`:

```js
const SHIFTS = [
  {id:'A', sup:'عبدالله الشيباني', anchor:'2026-07-18'},
  {id:'B', sup:'أحمد عبيد',        anchor:'2026-07-12'},
  {id:'C', sup:'محمود أبو طالب',   anchor:'2026-07-06'},
  {id:'D', sup:'حاتم الحربي',      anchor:'2026-06-30'},
];
```

`anchor` = أول يوم في وردية الصباح لتلك المجموعة.
